# 麻的小辛辣 排班系統（四週變形版）

單檔網頁排班工具，依勞動基準法 §30-1「四週變形工時」的規則排班，排的當下就檢核有沒有違法。

線上版：<https://eason0728.github.io/mala-schedule-4w/>

## 跟月曆版（mala-schedule）的差別

| | 月曆版 | 四週變形版 |
|---|---|---|
| 排班單位 | 曆月 | 28 天一期，跨月 |
| 休假 | 每週休 2 天 | 每週例假 1＋休息日 1，四週 8 天 |
| 換班間隔 | 不檢查 | 隔不到 11 小時的班不派 |
| 工時上限 | 無 | 每期正常工時 160 小時 |
| 檢核 | 班別需求 | 每期一張卡，標出違法項目與法條 |

兩套系統的瀏覽器資料鍵（`mala_` / `mala4w_`）與雲端檔案（`mala-schedule.json` / `mala-schedule-4w.json`）完全分離，可以同時使用，互不影響。

## 檢核規則

| 代號 | 規則 | 出處 |
|---|---|---|
| R1 | 四週排定正常工時 ≤160 小時 | §30 I，依 §30-1 I① 分配於四週 |
| R2 | 單日正常工時 ≤10 小時 | §30-1 I① |
| R3 | 單日正常＋延長 ≤12 小時 | §32 II |
| R4 | 每二週至少 2 日例假 | §36 II③ |
| R5 | 每四週例假＋休息日至少 8 日 | §36 II③ |
| R6 | 連續出勤 ≤12 日 | 內控（法令未設上限） |
| R7 | 換班間隔 ≥11 小時 | §34 II；餐飲業不在得縮為 8 小時的公告名單內 |
| R9 | 國定假日不得排為空班日「多」 | 內控 |
| R10 | 國定假日遇例假／休息日須補假 | 施行細則 §23-1 |

國定假日表只列法定假日本身。政府的補假與彈性放假屬公務員行事曆，民間企業依勞動部規定辦理，本工具不套用。

## 使用

`index.html` 是完整的應用程式，沒有建置步驟。用瀏覽器開啟即可；未設定雲端同步時，資料只存在該台裝置的 localStorage。

本工具不是法律意見，正式施行前請勞資顧問或律師確認。
